Privacy Policy — Points on Point

Last updated: May 2026

Points on Point is a Chrome extension designed to help users organize their daily tasks through a minimalist and elegant to-do list. It includes features such as recurring reminders (daily/weekly), notification sounds, inline task editing, drag & drop reordering, and bilingual support (English/Spanish).

We value your privacy. This extension does not collect, store, share, or sell any personal information. All data — including tasks, reminders, recurrence settings, display order, and user preferences (language, sound) — is stored locally in your browser using Chrome's storage API and is never transmitted to any external servers.

We do not use cookies, analytics, or any tracking technologies. All your information remains private and fully under your control.

The extension uses the following Chrome permissions solely to provide its functionality:

storage — to save your tasks and preferences locally.
alarms — to schedule and trigger reminders.
notifications — to display browser notifications for reminders.
activeTab, tabs, scripting — to show in-page toast notifications on the current tab.

If you have any questions or concerns regarding this privacy policy, please contact us at: sidmaierlabs@gmail.com

Política de Privacidad — Points on Point

Última actualización: Mayo 2026

Points on Point es una extensión de Chrome diseñada para ayudar a los usuarios a organizar sus tareas diarias mediante una lista de pendientes minimalista y elegante. Incluye funcionalidades como recordatorios recurrentes (diarios/semanales), sonido de notificación, edición inline de tareas, reordenamiento con drag & drop, y soporte bilingüe (inglés/español).

Valoramos tu privacidad. Esta extensión no recopila, almacena, comparte ni vende información personal. Todos los datos — incluyendo tareas, recordatorios, configuración de recurrencia, orden de visualización y preferencias del usuario (idioma, sonido) — se guardan localmente en tu navegador usando la API de almacenamiento de Chrome y nunca se envían a servidores externos.

No utilizamos cookies, análisis ni tecnologías de seguimiento. Toda tu información permanece privada y bajo tu control.

La extensión utiliza los siguientes permisos de Chrome exclusivamente para ofrecer su funcionalidad:

storage — para guardar tus tareas y preferencias localmente.
alarms — para programar y activar recordatorios.
notifications — para mostrar notificaciones del navegador para los recordatorios.
activeTab, tabs, scripting — para mostrar notificaciones tipo toast en la pestaña activa.

Si tienes alguna pregunta o inquietud sobre esta política de privacidad, puedes contactarnos en: sidmaierlabs@gmail.com
